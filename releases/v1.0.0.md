# Pico Swongle v1.0.0

One stable release with two firmware downloads for Raspberry Pi Pico 2 W. Both modes have been tested on a Switch 2 console and confirmed working.

- **`pico-swongle-switch1-v1.0.0.uf2`** — original Switch Pro Controller USB identity; motion and rumble, Home/Capture, and Bluetooth reconnect. Xbox Share maps to Capture.
- **`pico-swongle-switch2-v1.0.0.uf2`** — native Switch 2 Pro Controller USB identity; motion and rumble, with PS4/PS5 touchpad click or supported Xbox Share mapped to C/GameChat. PS5 Create remains Minus and Mute remains Capture.

Choose one UF2 and flash it using BOOTSEL. Connect to the dock with a USB data cable, enable Pro Controller Wired Communication, and pair your Bluetooth controller. The original Switch mode also works on Switch 2; native Switch 2 mode is intended for Switch 2.

Source and SHA-256 checksums are included. No controller audio/headset, NFC, grip-button mapping, adaptive triggers or console wake. See README for setup, mapping and license notices.
