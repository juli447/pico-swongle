Pico Swongle v1.1.0 adds tested DualSense audio on Switch 2 and smooth PS4/PS5 RGB lightbars.

### Downloads

- **pico-swongle-switch1-v1.1.0.uf2** — original Switch Pro Controller identity, with RGB. Also usable on Switch 2. No controller audio or C button.
- **pico-swongle-switch2-v1.1.0.uf2** — native Switch 2 Pro Controller identity, with C/GameChat, RGB and DualSense headphone/internal-speaker playback.
- **pico-swongle-v1.1.0-source.zip** — source and license notices.
- **SHA256SUMS** — checksums for both UF2 files and the source archive.

Flash one UF2 at a time. Both firmware downloads belong to this single stable release.

### Controls

- **Hold Touchpad, then press PS:** RGB on/off. Home alone works immediately, including long holds.
- **Touchpad + Mute, without headphones:** normal console audio / internal DualSense speaker.
- **Headphones inserted:** always play through headphones; unplugging restores the previous output choice.
- Existing motion, rumble, Home/Capture and native C/GameChat mappings remain.

The user confirmed smooth audio, speaker switching, RGB and the final Home shortcut on Switch 2 with a DualSense. USB receive servicing fixes the rare gaps encountered during development; there is no large extra-latency audio buffer. RGB yields to audio traffic. The latest original Switch build and PS4 lightbar support pass build/host checks; no separate latest-build PS4 console test is claimed.

Playback only: headset microphone forwarding and PS4/Xbox audio are not included. The audio-enabled Switch 2 build runs at the tested 300 MHz / 1.20 V configuration, above the Pico 2 W’s standard CPU clock. Diagnostic tone and audio blink diagnostics are disabled in release firmware.

Firmware builds and input, RGB, motion, rumble, USB, audio/Opus, routing and UAC regression tests pass. See the README and audio documentation for setup and limits. Previous v1.0.0 downloads remain available.
