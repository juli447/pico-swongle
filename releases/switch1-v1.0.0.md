# Pico Swongle — Switch v1.0.0

Original Switch Pro Controller USB personality for Pico 2 W. This is the stable release based on the DualSense firmware confirmed working on Switch 2, with a 15% per-axis deadzone, motion and conventional rumble.

Flash `pico-swongle-switch1-v1.0.0.uf2` using BOOTSEL, enable Pro Controller Wired Communication, connect to the dock, and pair your Bluetooth controller. Xbox Share remains Capture; this personality has no C button.

Source regression tests and RP2350 firmware build pass. Xbox/PS4 compatibility depends on the Bluetooth controller and has not been physically verified in this project. See README for mapping, setup and licenses.
